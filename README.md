# Очаково Квест

Игровой сайт для привлечения студентов и выпускников 18–26 лет в «Очаково».
Вместо теста с вопросами: путь по заводу в стиле Duolingo, пять разных мини-игр, маскот Бочик и пропуск на стажировку в финале.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Что внутри

**Путь (core loop).** Четыре раздела-цеха, уровни открываются по очереди. Каждый уровень даёт опыт, крышечки (внутренняя валюта) и карточку-факт о компании.

| Уровень | Механика | Чему учит |
|---|---|---|
| Машина времени | Вставить событие в нужное место ленты времени (как в настолке «Таймлайн») | История компании с 1978 года |
| Сварим квас | Симулятор: собрать сусло, удерживать температуру, запустить брожение, охладить | Производство и роли: аппаратчик, технолог, КИПиА |
| Зоркий глаз | Аркада: снимать брак с ускоряющегося конвейера, серии умножают очки | Контроль качества и ОТК |
| Карьерный компас | Свайп-карточки, как в Tinder, подбирают одно из 7 направлений | Профессии на заводе |
| Первый год | Сюжет с выборами, у каждого выбора своя прокачка | Наставничество, обучение, ротации, рост |
| Пропуск | Голографический бейдж и форма заявки на стажировку | Конверсия в реальный отклик |

**Мета-слой.** Уровни игрока, серия дней, задания дня, сундуки со случайной наградой, 8 значков, демо-лига, магазин аксессуаров для маскота, коллекция фактов.
Прогресс хранится в `localStorage`; повторное прохождение даёт уменьшенную награду.

**Дизайн.** Палитра и «3D»-кнопки в духе Duolingo, шрифт Nunito, светлая и тёмная темы.
Все иллюстрации нарисованы вручную как анимированные SVG: завод, танк с живой жидкостью, конвейер, маскот с настроениями и следящими за курсором глазами.
Переходы в духе промо-роликов: круговая заливка из нажатого узла, затем титульная карточка с кинетическим текстом. Звуки синтезируются через WebAudio.
Анимации учитывают `prefers-reduced-motion`.

## Структура

```
src/data/content.ts      весь текст и факты: проверять здесь
src/state/store.ts       прогресс, XP, валюта, серии, задания (zustand + persist)
src/games/*              пять мини-игр
src/screens/*            онбординг, путь, раннер уровней, сундук, пропуск, вкладки
src/components/*         маскот, SVG-сцены, общие UI-элементы
```

## Перед показом

- Факты из `content.ts`, помеченные `VERIFY` (программы стажировок, описания направлений), стоит сверить с HR «Очаково».
  Подтверждены по открытым источникам: основание в 1978 году, связь с Олимпиадой-80, приватизация в 1993 году, второе место по доле рынка в 2018 году.
- Форма заявки пока сохраняет данные только в браузере. Для продакшена нужен бэкенд или интеграция с HR-системой.
- Лига демонстрационная, с тестовыми игроками.
