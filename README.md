# Очаково Квест

Игровой сайт для привлечения студентов и выпускников 18–26 лет в «Очаково».
Вместо теста с вопросами: путь по заводу в стиле Duolingo, пять разных мини-игр, маскот Бочик и пропуск на стажировку в финале.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Концепция: «Первая партия»

Игрок не читает о компании, а работает в ней: за пять смен выводит на полку собственный квас.
Решения из ранних смен влияют на поздние. В финале он получает бутылку с именной этикеткой (её можно скачать или отправить) и профиль навыков, собранный из стиля игры, а не из теста.

| Раздел | Смена | Механика | Что узнаёт игрок |
|---|---|---|---|
| Узнать | Экскурсия | 6 интерактивных эпох: дёрнуть рубильник 1978 года, запустить линии Pepsi и Fanta 1979-го, добавить закваску 1996-го, зажечь заводы на карте | История с 1978 года, без угадывания дат |
| Придумать | Маркетинг | Свайп инсайтов из интервью, выбор концепта, название и этикетка | Как рождается продукт, реальные аналоги из портфеля |
| Придумать | Лаборатория | Головоломка с рецептом: кислота не регулируется, она растёт от времени брожения | Двойное брожение, своя закваска, свой солод |
| Произвести | Варочный цех | Трубы от водоподготовки, затор, брожение в танке, решение «фильтровать или нет» | Масштаб цеха (65 000 и 700 000 л), инженерные роли |
| Произвести | Контроль качества | Аркада: снимать брак с конвейера | ОТК, 1000 бутылок в минуту |
| Продать | Продажи | Логистика по карте 4 заводов и переговоры с сетью, где аргументы опираются на твои прошлые результаты | География компании, коммерческие роли |

**Как подаётся информация:**
- Перед каждой сменой наставник рассказывает, как вырос внутри компании (собирательный образ).
- После решения игрока появляется карточка «А как это делает Очаково».
- Каждая смена даёт экспонат в **Музей**.

**Мета-слой:**
- XP, уровни, серия дней, задания дня;
- сундуки со случайной наградой, значки;
- **Кубок вузов** (опыт идёт в зачёт вуза);
- магазин аксессуаров для маскота.

## Структура

```
src/data/content.ts      весь текст и факты (с источниками в шапке файла)
src/state/store.ts       прогресс, XP, валюта, серии, задания (zustand + persist)
src/games/*              экскурсия и пять смен
src/screens/*            онбординг, путь, раннер уровней, сундук, пропуск, вкладки
src/components/*         маскот, SVG-сцены, общие UI-элементы
```

## Перед показом

- Исторические и производственные факты взяты из Википедии и статьи на ochakovo.ru «Как делают настоящий квас». Список источников в шапке `content.ts`.
- С HR «Очаково» стоит сверить наставников, лестницы карьеры и программы стажировок. Сейчас это правдоподобные примеры, в интерфейсе они подписаны как «собирательный образ» и «примеры направлений».
- Форма заявки пока сохраняет данные только в браузере. Для продакшена нужен бэкенд или интеграция с HR-системой.
- Кубок вузов демонстрационный, с тестовыми данными.
